# scripts

Developer helper scripts. Phase 0 has none with logic. Phase 1 will add, for
example, a seeding helper that loads a config's synthetic policy snippets into
the pgvector store and a local-run helper that brings up the compose stack and
runs one synthetic sample.

Do not place any real client data or secrets in scripts. See
[../docs/data-privacy.md](../docs/data-privacy.md).
